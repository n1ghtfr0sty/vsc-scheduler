# 2026-07-11

## Feature: User management — create / edit / delete (issue #8)

- **Spec:** `docs/superpowers/specs/2026-07-11-user-management-design.md` (committed).
- **Backend:**
  - `src/db.js` — enabled `PRAGMA foreign_keys = ON` on the app connection. The schema's `ON DELETE CASCADE` rules never fired before this (SQLite defaults the pragma to OFF per connection); app-side deletes were leaving orphaned child rows.
  - `src/routes/users.js` — added admin-only `POST /` (create user: name/email/password/role/phone, bcrypt hash, case-insensitive email uniqueness, no permission rows — non-admins start with none, admins bypass permissions entirely), `PUT /:id` (edit name/email/phone + optional password reset; role stays on the existing `PUT /:id/role`), and `DELETE /:id` (404 missing, 400 self-delete, 400 last-admin, cascade removes family → players → player_teams / coach → team_coaches / user_permissions).
- **Frontend:**
  - `public/js/api.js` — `API.users.create/update/delete`.
  - `public/js/app.js` — "+ Add User" button on the Users page header; per-card Edit and Delete buttons (Delete hidden on the logged-in admin's own card); `showUserForm()` create/edit modal (password field is "leave blank to keep" in edit mode); `confirmDeleteUser()` confirmation modal with role-aware cascade warning; user names/emails on cards now escaped with `escapeHtml`.
- **Verification:** headless Chrome + API probes against a :3999 instance running on a **copy** of the DB (`DB_PATH` env var — new isolation trick, recorded in `.claude/skills/verify/SKILL.md`):
  - Create → user appears; login works. Edit → rename persists; old password rejected, new password logs in.
  - Delete → confirmation modal shows cascade warning; cancel keeps user; confirm removes from list.
  - Direct-DB cascade check: deleting a family user removed users/families/players/player_teams/user_permissions rows (all zero after).
  - Guards: self-delete 400, duplicate email (case-insensitive) 400, invalid role 400, missing user 404, coach session 403 on POST and DELETE.
